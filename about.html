About CityRide

An academic project demonstrating online bus pass registration for students and commuters.

Passenger services

Passengers can apply online, track their application, and print an approved digital pass.

Application review

Administrators can look up registered passengers and approve or reject applications.

How the demo works

CityRide uses HTML, CSS, and JavaScript. Accounts and applications are stored in the browser.

Project scope

This Web Technologies project uses demonstration passes. Applications stay in this browser and are never sent to a transport department.
